OUTPUT

RULES
- Output must be in English.
- Describe interface properties only.
- Do not describe the user, medical conditions or environment unless directly relevant as visible context.
- Use the scenario and dimensions as evidence.
- Provide a concise rationale for each value.
- All values use the internal 0-100 model scale.
- Higher values mean stronger presence of the respective attribute, except where the schema explicitly defines supportive attributes.
